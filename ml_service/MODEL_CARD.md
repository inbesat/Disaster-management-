# Model Card — Flood Risk Classifier (XGBoost)

**Project:** SafeSphere Platform
**Model:** Gradient-boosted decision tree (`XGBoost` classifier)
**Task:** 4-class flood risk classification
**Served by:** FastAPI microservice (`ml_service/api.py`)

---

## 1. System Architecture

```
┌─────────────────────────┐      ┌──────────────────────┐      ┌──────────────────────────┐
│   Next.js (Frontend)    │      │  FastAPI (Python)    │      │     XGBoost model        │
│  lib/ml-client.ts       │ HTTP │  ml_service/api.py   │ joblib │  flood_xgboost_model.pkl │
│  /api/predict           │ ───► │  /predict            │ ────► │  predict_proba()         │
└─────────────────────────┘      └──────────────────────┘      └──────────────────────────┘
                                        │
                                        ▼
                             ┌──────────────────────┐
                             │   PostgreSQL          │
                             │  flood_predictions    │  (persisted via Prisma)
                             └──────────────────────┘
```

**Flow:**
1. The map's `onMoveEnd` / geolocate (or the **What-If Simulator** sliders) fires a request to the Next.js route `GET /api/predict?lat=&lng=&rainfall=&saturation=&elevation=`.
2. `lib/ml-client.ts` formats the 4-model-features payload and POSTs it to the FastAPI service (`http://127.0.0.1:8000/predict`).
3. FastAPI loads the trained `flood_xgboost_model.pkl` on startup, runs `predict_proba`, and returns the predicted class + confidence.
4. `lib/ml-client.ts` maps class `0-3` to the UI labels **Safe / Watch / Warning / Evacuate**, persists the row to `flood_predictions`, and returns it to the UI.
5. If the Python service is unreachable, the API returns HTTP 503 with risk unavailable. It never substitutes a `Safe` result. Predictions are experimental, and automated alert dispatch is disabled unless `ML_AUTO_ALERTS_ENABLED=true`.

## 2. Features

| Feature | Type | Meaning |
|---------|------|---------|
| `cumulative_rainfall_72h` | float (mm) | Total rainfall over the last 72 hours |
| `river_level_trend` | float (m) | Rate of river level change over 72h |
| `soil_saturation_index` | float (0–1) | How saturated the soil is (1 = fully saturated) |
| `elevation_m` | float (m) | Terrain elevation — low-lying areas are far riskier |

## 3. Target Classes

| Class | Label (UI) | Meaning |
|-------|------------|---------|
| 0 | **Safe** | Low risk, no action required |
| 1 | **Watch** | Monitor closely, prepare |
| 2 | **Warning** | Evacuation preparation / movement to shelters |
| 3 | **Evacuate** | Immediate evacuation recommended |

The target is engineered to correlate with high 72h rainfall, rising river trends, high saturation, and low elevation — the same physics that drive real flooding.

## 4. Training

- **Dataset:** `historical_flood_data.csv` — 1,030 rows:
  - **30 rows** extracted from real disaster PDFs (44 documents in `ML_DATABASE/`):
    Wikipedia flood articles, CWC flood-forecasting methodology, NDMA reports,
    disaster-management papers, and India flood news reports. Extracted via
    `extract_real_data.py` (regex-based rainfall/river/elevation extraction).
  - **1,000 rows** synthetically generated by `generate_data.py` (physics-based).
- **Features:** the 4 above; **target:** `risk_level` (0–3).
- **Split:** 80/20 stratified train/test.
- **Model:** `XGBClassifier` (300 estimators, depth 6, lr 0.1, early stopping).
- **Metrics (test set):** Accuracy ≈ **0.78**; F1 ≈ 0.77 (macro).
- **Feature importances:** river_level_trend (0.30), cumulative_rainfall_72h (0.29),
  elevation_m (0.23), soil_saturation_index (0.18).
- **Export:** `flood_xgboost_model.pkl` via `joblib`.

## 5. Data Provenance

Training data combines **real disaster documents** with synthetic augmentation:

**Real data sources (30 records from 12 PDFs):**
- Wikipedia flood articles (2019 Indian floods, 2023 South Asian floods, 2024 India floods)
- CWC (Central Water Commission) flood-forecasting methodology papers
- NDMA disaster management reports
- Academic flood vulnerability studies (PMC, sustainability research)
- India disaster statistics (India Floods 2025, monsoon flash floods)

**Synthetic augmentation (1,000 rows):**
Generated by `generate_data.py` using gamma-distributed rainfall with derived
saturation and river-trend features. Class distribution: ~35% Low, ~35% Medium,
~20% High, ~10% Critical.

**How to retrain:**
1. Add new PDFs to `ML_DATABASE/` or replace `historical_flood_data.csv`.
2. Run `python extract_real_data.py` (for PDFs) or `python generate_data.py` (synthetic).
3. Run `python train_model.py` → exports new `flood_xgboost_model.pkl`.
4. Restart the FastAPI service; no frontend changes required.

## 7. Limitations

- Trained on a mix of real (30 records) and synthetic (1,000 records) data;
  real-world accuracy improves as more PDFs are processed or IMD/CWC data added.
- Regex-based extraction captures numerical patterns but misses context;
  LLM-based extraction (Groq/OpenAI) available as upgrade path via
  `extract_pdf_data.py` when API keys are configured.
- Point-prediction only (no spatial interpolation across catchments yet).
- Does not yet model river-embankment breaches or drainage topology.
